# AP – Python : les exemples du cours

Le code montré sur les slides, séance par séance, pour l'essayer sans rien recopier.

```bash
git clone https://github.com/raphaelpra/ap-python-exemples
cd ap-python-exemples
git pull        # en début de séance, pour récupérer les nouveaux exemples
```

| Dossier | Séance |
|---|---|
| `S1/` | Snake procédural |

Un fichier se lance avec `uv run fichier.py` (ou `python fichier.py`). Devinez ce qu'il affiche **avant** de le lancer.

Ce dépôt ne contient que les exemples : vos TP se font dans votre dépôt `python-homework`.
